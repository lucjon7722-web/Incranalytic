# Incranalytic Studio 0.5.0 — first public development release

This Windows studio for human-authored incremental systems adds sidebar
navigation, searchable System/IFCLOUD manuals under Help, a six-page first-run
walkthrough and optional example, workspace hints, code line numbers/keyword
colors, and view options. Simulation settings start hidden; local recovery starts enabled.

Recovery copies are separate from saved projects, include open code drafts, and
are offered after interruption. Uninstall offers independent optional recovery
deletion. Save/Save as and close prompts protect authored work.

The reusable Version Manager now starts anonymously. Public downloads need no
token; private access is optional. Use the versioned Setup EXE offline or keep
Incranalytic-Installer.exe for version selection. Both include private .NET runtimes.

The studio has been built with substantial **GPT-6.1SOL** assistance because its
creator works alone, is inexperienced, and has no funding or team. See
[the disclosure](https://github.com/lucjon7722-web/Incranalytic/blob/main/docs/AI-DEVELOPMENT.md).
The product has no AI generator/service: people author systems and the studio
calculates them. Source is public under reserved terms. Exports and required
runtime files permit personal/commercial use, modification, and distribution.

Checks cover arithmetic, IFCLOUD, graphs, recovery, application flows, verified
downloads, and isolated installation/removal on the development Windows host.
Exported C# is compared using a Unity API stub. These unsigned packages have
not been tested in a clean VM or actual Unity editor.
