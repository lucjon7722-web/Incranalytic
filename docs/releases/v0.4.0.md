Incranalytic 0.4 adds a reusable installer / Version Manager. Keep it to choose studio versions without downloading a new launcher each time.

## Get started

- **Incranalytic-Installer.exe** is the reusable standalone Version Manager. Keep this file. It includes its runtime and can list and install future releases.
- **Incranalytic-0.4.0-Setup.exe** installs studio 0.4 directly, including the Version Manager under **Help → Install / manage versions** and a Start menu shortcut.
- The manager lets you select older releases, read notes, cancel downloads and reuse a verified cached installer. Install one studio version at a time using the usual setup wizard.

Save and close the studio before installing a different version. Older versions may not open newer project formats; retain project backups and the standalone manager when downgrading.

## Private GitHub access

This repository remains private. The manager needs a user-provided fine-grained GitHub token scoped to this repository with **Contents: Read**. Browser sign-in is not reused. Remembering is optional through Windows Credential Manager; Forget deletes saved access. No credentials are embedded in downloads or project files. The studio itself works offline without a token.

The manager sends tokens only to api.github.com. Installer downloads are checked for exact filename, size, SHA-256 and matching GitHub asset digest before execution. Corrupted, incomplete, cancelled or foreign-host downloads are rejected. Normal installer language, destination, terms, shortcut and uninstall options remain available.

## Validation

Tests include the real private GitHub catalog and verified downloads of both v0.2.0 and v0.3.0, plus simulated corrupted and interrupted streams, cancellation, host restrictions, token isolation, release sorting, manager UI and disposable Windows-credential round trips. The packaged studio and manager are checked after isolated installation, including uninstall dependency retention/removal and user-project preservation.

These remain unsigned development packages. Clean Windows VM and real Unity editor integration remain untested. The manager may itself need an update if the release protocol or security requirements change. Future studio releases must retain the published versioned setup/checksum filenames; the release script includes the reusable manager assets.

The Workspace, IFCLOUD, simulation and Unity export features from 0.3 remain included. No AI service generates systems in the product; development has used AI assistance.
