# Incranalytic by Kitarie

**Kitarie is the creator of Incranalytic Studio**, a Windows desktop application
for designing, simulating, and understanding human-authored incremental systems.
This repository is the official source and documentation home for the project.

## Incranalytic and IFCLOUD

Incranalytic is the application. **IFCLOUD** is its custom numeric rule language
for workspace modules. Write formulas and conditional IFCLOUD code, connect
blocks, and inspect the calculations that drive your system.

The studio supports values, production loops, feedback memory, simulation
tables, graphs, reusable modules, and C# export with supporting runtimes for
Unity. It is intended for people developing or exploring numerical systems,
including incremental game progression.

## Development and ownership

Kitarie directs the project. Development has used substantial AI assistance,
documented in [how Incranalytic is made](AI-DEVELOPMENT.md). The app itself has
no AI system generator: users author the rules, formulas, and connections.
