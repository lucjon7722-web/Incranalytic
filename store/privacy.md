# Incranalytic Studio privacy policy — Microsoft Store edition

Effective date: November 3, 2026.

Incranalytic is a personal project by Kitarie. The Microsoft Store edition runs
your authored systems locally. It does not require an Incranalytic account,
collect telemetry, include advertising or analytics SDKs, send projects to an
AI service, or upload your values, rules, and simulation results.

## Data on your computer

Projects contain authored values, code, graph connections, and settings.
Preferences store interface choices and walkthrough status. Automatic recovery
copies can include unfinished code and the original project path. Recovery
starts enabled and can be turned off from View. Save files, exports, CSVs, and
backups are written to locations you choose. Windows manages packaged app data;
retain important projects and backups outside app-managed storage. Removing
the app can remove its app-managed preferences and recovery data.

## Microsoft Store

This edition does not contain the GitHub Version Manager or request GitHub
tokens. Installation, updates, and removal are managed by Microsoft Store.
Microsoft's handling of account, installation, diagnostic, and usage information
is governed by the [Microsoft Privacy Statement](https://privacy.microsoft.com/privacystatement).
The studio itself does not send telemetry to the developer.

## Voluntary support

If you choose to open a support issue, GitHub processes your account and submitted
content under its own terms. Public issues are visible to others. Share only the
project excerpts and diagnostic information you intend to publish. The developer
uses voluntarily supplied information to investigate and respond to the issue.
You can edit or remove your own submissions using GitHub's controls; public
copies made by others may remain.

Support and privacy requests: [Incranalytic issues](https://github.com/lucjon7722-web/Incranalytic/issues).
For a request involving personal information, first ask for a private contact
method without posting the information itself. No private support email has
been designated in this draft submission.

## Changes

Policy updates will be published with a new effective date. This policy describes
the Store edition; the optional GitHub Version Manager in separately distributed
desktop releases has different network and credential behavior.
