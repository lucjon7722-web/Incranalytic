# Third-party components

Incranalytic's reserved source terms do not replace third-party licenses.

- Microsoft .NET and Windows Forms are bundled privately with official Windows
  builds. Their `LICENSE.txt` and `ThirdPartyNotices.txt` are included alongside
  the application. See https://github.com/dotnet/runtime and
  https://github.com/dotnet/winforms for upstream source and notices.
- Setup and uninstallation are built with Inno Setup 6.7.4 by Jordan Russell and
  Martijn Laan. Inno Setup's copyright and website information remain in the
  installer. https://jrsoftware.org/ — https://jrsoftware.org/isorder.php
- GitHub hosts the source and downloads. It is not an embedded application
  dependency. Unity is a target for exported C#; Unity is not bundled or required
  to run the studio.

There are no AI model services, downloaded language models, Java, Python, Unity,
Godot, or other engine installations required by the base studio. The Version
Manager is optional for downloading releases. New dependencies are not added by
this release.
